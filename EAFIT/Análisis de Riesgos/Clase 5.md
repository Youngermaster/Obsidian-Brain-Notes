## Análisis Cuantitativo de Riesgo
Este método permite aproximar las pérdidas del proyecto de una manera más exacta, para esto se utilizan diferentes métodos cuantitativos para evaluar la probabilidad de pérdida del proyecto, esta dependerá del *Tipo de Información*. Con la que cuente el proyecto para hacer la modelación.

## Información
- Expertos
	- [[Asignación de funciones de distribución]]
	- Bass
- Histórica
	- PBA
	- Series de Tiempo.

Para transformar una variable del proyecto en una variable aleatoria se debe hacer la asignación de una función de distribución, estas dependen de 3 características:
- Limitación/Truncamiento
	- Ilimitadas/No Truncadas
	- Parcialmente limitadas/Parcialmente Truncadas
	- Limitadas/Truncadas
- Naturaleza de la variable aleatoria
	- Discretas
	- Continuas
- Parametros
	- Paramétricas
		- Funciones de Distribución teóricas
	- No Paramétricas
		- Empíricas

---
Variables del proyectos => Aleatoriedad de las variables (Cambios que se presentan en los inputs del proyecto) => Efecto en los resultados del proyecto => VPN, TIR, R B/C, Payback => Simulación de Montecarlo
